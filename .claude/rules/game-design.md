# 기획 논의 규칙

자세한 가이드는 `game-design` skill 참조.

## 논의 방식
- 분석과 제안만 한다
- 문서/CSV 수정은 사용자가 명시적으로 요청할 때만 진행

## 확정 사항
- 장르: 웹 RPG (아이템 파밍 + 영웅 육성)
- 배경: Aurea (7대 죄악 세계관)
- 5스탯: 힘(STR)/민첩(DEX)/체력(VIT)/운(LCK)/지능(INT)
- 바알: HoMM3식 지휘관 (전투 밖에서 레벨 기반 버프, 슬롯 차지 안 함)
- 파티: 영웅 3인 자유 편성
- 직업 5종: warrior/knight/mage/assassin/healer (전직 없음)
- 자동 전투 (행동력 기반 턴제)
- 7챕터 구조 (분노 ~ 교만)
- 진영: 인간 / 악마 / 천상 (3진영 시너지)
