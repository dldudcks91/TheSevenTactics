# 구현 워크플로우 (필수 준수)

구현 및 리팩토링 작업 시 반드시 아래 6단계를 순서대로 진행한다.
단계를 건너뛰거나 사용자 확인 없이 다음 단계로 넘어가지 않는다.

**참조 스킬:**
- `fastapi-server` — 아키텍처 패턴
- `manager-convention` — Manager 코드 레벨 규칙

---

## 0단계: 기능 확인

구현 시작 전, 해당 기능의 범위를 사용자와 확인한다.

## 1단계: 개발 계획 생성

- **목적** — 기능/목적 한 줄 요약
- **작업 유형** — 신규 개발 / 리팩토링 / 버그 수정
- **변경 파일** — 신규/수정/삭제 파일 목록
- **구현 순서** — 단계별 작업 순서

계획 제시 후 **사용자 승인**을 받는다.

## 2단계: 개발 계획 검증

6대 관점: 아키텍처 정합성, 트랜잭션 안전성, 보안/어뷰징, 성능, 에러 처리, 유지보수성

## 3단계: 구현

검증을 통과한 계획대로 코드를 작성한다.

## 4단계: 구현 결과 테스트

- 서버 기동 테스트
- 기능 테스트 (성공 + 에러 케이스)

## 5단계: 결과 저장 및 문서 업데이트

- DEV_PLAN.md 상태 갱신
- 변경 사항 보고
