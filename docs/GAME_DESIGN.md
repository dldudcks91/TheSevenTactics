## 1. 게임 개요

- **장르**: 웹 RPG (영웅 육성 + 아이템 파밍 + 파티 전투)
- **배경**: Aurea — 신이 걸었던 땅, 7대 죄악이 지배하는 다크 판타지 세계
- **핵심 재미**: 내 캐릭터(바알) 빌드 + 용병 조합 + 장비 파밍
- **컨셉**: "타락한 마왕이 인간의 몸으로 7대 죄악을 정복하고, 배신의 진실을 밝힌다"
- **플랫폼**: 웹 브라우저 (PC)
- **참고 게임**: 아포칼립스 (동양온라인, 2010), 디아블로 시리즈

### 핵심 루프

```
[사냥] 스테이지 입장 → 3v3 자동 전투 → 아이템/경험치 획득
    ↓
[성장] 바알 스탯 투자 / 스킬트리 배분 / 장비 장착
    ↓
[전략] 바알 빌드에 맞는 용병 영입 → 3인 파티 조합
    ↓
[도전] 다음 스테이지 / 챕터 보스
    ↓
[판단] 실패 시 → 장비 파밍 / 스탯 재배분 / 용병 교체
    ↓
반복
```

### TheSevenRPG와의 차이점

| 항목 | TheSevenRPG | TheSevenTactics |
|------|-------------|-----------------|
| 전투 | 1:1 자동전투 | **3인 파티 vs 적 다수** |
| 본캐 | 없음 (전원 동등) | **바알 = HoMM3식 지휘관 (전투 밖에서 버프)** |
| 용병 | 다른 유저 캐릭 빌림 | **선술집에서 영입한 내 영웅** |
| 스킬 | 카드 장착 → 트리거 자동발동 | **스킬트리 직접 투자** |
| 카드 | 몬스터 카드 수집 + 스킬 | **삭제** |
| 코스트 | 장비 착용 제한 스탯 | **삭제** |
| 스탯 | STR/DEX/VIT/LCK/CST | **STR/DEX/VIT/LCK/INT** |

## 2. 세계관 및 스토리

### 세계 배경 — Aurea (아우레아)

태초에 하나의 신이 세계를 창조하고, 자신을 7개의 감정으로 나누어 세계의 균형 장치로 심었다:
**분노(Wrath), 나태(Sloth), 탐욕(Greed), 질투(Envy), 폭식(Gluttony), 색욕(Lust), 교만(Pride).**

그러나 인간은 이 죄악을 관리하는 대신 **소유하려** 했다.
균형이 무너졌다. 신은 쓰러졌다. 7개의 감정은 세계 곳곳에 흩어진 **타락한 죄악의 화신**이 되어, 각 지역을 자신의 색으로 물들였다.

### 플레이어 — 바알(Baal), 낙인을 품은 자

플레이어는 **바알**, 한때 마왕이었던 존재다.

바알은 자신의 7가지 감정을 7명의 하인에게 나누어 지옥의 균형을 유지했다.
그러나 어느 밤, **배신의 밤** — 7자루의 칼이 바알의 등을 찔렀다.
힘은 빼앗기고, 기억은 흐려지고, 바알은 인간의 몸으로 떨어졌다.

### 스토리 진행

- **챕터 기반 진행**: 7대 죄악을 하나씩 정복하며 배신의 진실에 다가감
- **동료 영입**: 선술집에 찾아오는 악마/인간/천상 존재를 용병으로 고용
- **성경 모티프**: 각 챕터가 성경의 이야기와 대응

### 배신의 밤 — 진실의 구조

```
[대천사 티리엘] → 모든 배신을 설계한 흑막
    ↓
[벨제붑] → 충동적으로 서약(Covenant)을 넘겨줌
    ↓
[레비아탄] → "죽이지 마라, 모든 것을 빼앗고 아무것도 아닌 것으로 떨어뜨려라"
    ↓
[마몬] → 거래를 성사시킴 (대가를 받은 자)
    ↓
[벨페고르] → 알고 있었지만 침묵 (방관한 자)
    ↓
[아스모데우스] → 처음부터 티리엘의 첩자
    ↓
[사탄] → 이미 추방된 상태, 배신과 무관하게 독자적으로 추격
    ↓
[루시퍼] → 배신하지 않았다. 바알을 살리기 위해 "죽이지 않는 추락"을 유도
```

## 3. 캐릭터 시스템

### 바알 = HoMM3식 지휘관

바알은 **전투에 직접 참여하지 않는 지휘관**. HoMM3의 영웅처럼 전투 밖에서 파티 전체에 레벨 기반 버프를 제공.
28체 영웅은 전부 **동일한 육성 시스템** 적용 (전원 동등).

> **설정**: 마왕 바알이 전투력을 잃고 인간의 몸으로 떨어져, 지휘관으로서 동료를 이끌며 7대 죄악에 복수하는 여정.

**바알 지휘관 버프 (레벨 기반)**

| 버프 | 계수 (/레벨) | 설명 |
|------|-------------|------|
| 공격력 % | +1% | 아군 전체 ATK/MATK 증가 |
| 방어력 % | +1% | 아군 전체 DEF 증가 |
| 최대 HP % | +0.5% | 아군 전체 HP 증가 |
| 치명타 보정 | +0.2 | 아군 전체 치명타 확률 보정 |

```
영웅 공통 구조 (28체 동일)
├── 베이스 스탯 (영웅마다 고정, hero_base.csv)
├── 고유 패시브 (영웅마다 1개, 고정)
├── 직업 (5종, 영웅 특성으로 결정 — 전직 없음)
├── 죄종 선택 (7죄종 중 택1) → 해당 특성풀 개방
├── 특성 포인트 배분 (유저 선택)
├── 메인 스킬 (고정) + 접사 스킬 (등급별)
└── 장비 3슬롯 자유장착 (무기/갑옷/기타 중 자유 선택)
```

### 직업 5종 (전직 없음)

직업은 영웅의 특성으로 결정 (hero_base.csv에 고정). 전직 시스템 없음.

| 직업 | 주스탯 | 역할 | 메인스킬 성격 |
|------|--------|------|--------------|
| **전사(Warrior)** | STR | 근접 물리 딜러 | 단일/소수 고데미지 |
| **기사(Knight)** | VIT | 탱커/보호 | 도발/방어/반격 |
| **마법사(Mage)** | INT | 마법 딜러 + 디버프/CC | 광역 마법 공격, 상태이상 |
| **암살자(Assassin)** | DEX+LCK | 속도/치명타 | 빠른 연타/즉사 |
| **힐러(Healer)** | INT+VIT | 힐/버프/부활 | 아군 지원 |

### 직업별 영웅 분류

| 직업 | 영웅 (체수) |
|------|------------|
| **전사** (5) | 사탄, 벨제붑, 아바돈, 둘라한, 네피림 |
| **기사** (5) | 벨페고르, 몰록, 아스타로트, 파주주, 다곤 |
| **마법사** (9) | 메피스토펠레스, 릴리스, 유키온나, 세라핌, 레비아탄, 아스모데우스, 나르키소스, 인큐버스, 사이렌 |
| **암살자** (4) | 마몬, 레기온, 아비주, 사마엘 |
| **힐러** (4) | 루시퍼, 밴시, 카론, 메타트론 |

> 마법사가 기존 마법 딜러 + 주술사(디버프/CC) 통합. 마법사 내에서 딜러형/CC형은 고유 패시브와 접사로 분화.

### 스킬 구조 (접사 기반)

| 구성 | 설명 | 결정 시점 |
|------|------|----------|
| 메인 스킬 | 영웅 고유 액티브 | 고정 |
| 접사 스킬 | 7죄종 접사에서 파생된 추가 스킬 | 영입 시 랜덤 |

**등급별 스킬 슬롯**

| 등급 | 메인스킬 | 접사슬롯 | 고유슬롯 | 총 스킬 |
|------|---------|---------|---------|--------|
| Normal | 1 (고정) | 0 | 0 | 1 |
| Magic | 1 (고정) | 1 (랜덤) | 0 | 2 |
| Rare | 1 (고정) | 2 (랜덤) | 0 | 3 |
| Unique | 1 (고정) | 1 (랜덤) | 1 (고유 강화) | 3 |

### 특성 시스템

전직 시 7죄종 중 1개를 선택하면 해당 죄종의 특성풀이 개방. 레벨업으로 특성 포인트 획득, 유저가 직접 배분.

```
영웅 특성 탭
├── [고유 탭] 영웅 고유 특성 (항상 보유)
└── [죄종 탭] 선택한 죄종의 특성풀
    ├── 공용 특성 (직업 무관)
    ├── 물리 계열 (전사/기사/암살자 전용)
    └── 마법 계열 (마법사/힐러 전용)
```

특성풀 규모: 7죄종 × (공용 2 + 물리 2 + 마법 2) = **42개** + 고유 특성 28개 = **총 70개**

### 파티 구성

- **파티 최대 3인** (28체 중 자유 편성, 바알은 지휘관이므로 슬롯 차지 안 함)
- 같은 영웅 보유 불가 (1체만)
- 직업 제한 없음 (전사 3인 파티 등 허용)

### 포지션 (2열 시스템)

```
아군 진형              적군 진형
┌──────────┐          ┌──────────┐
│ [전열]   │          │ [전열]   │
│ 슬롯1    │    VS    │ 적1      │
│ 슬롯2    │          │ 적2      │
├──────────┤          ├──────────┤
│ [후열]   │          │ [후열]   │
│ 슬롯3    │          │ 적3      │
└──────────┘          └──────────┘
```

| 규칙 | 설명 |
|------|------|
| 전열 우선 피격 | 단일 공격 → 전열 대상만 |
| 후열 보호 | 전열 전멸 시 후열 → 전열 전환 |
| 범위 스킬 | 전체 공격은 열 무시 |
| 배치 설정 | 파티 편성 시 유저가 전열/후열 지정 |

### 아트 컨셉

| 구분 | 톤 | 설명 |
|------|-----|------|
| **아군 영웅** | 밝은 톤, 채도 높음 | 인간형에 가까운 악마 (뿔/꼬리 정도), 갑옷/무기 착용, 영웅적 포즈 |
| **적 몬스터** | 어두운 톤, 탁한 색 | 괴수형/완전 이형 악마, 날것 그대로, 위협적 포즈 |

> 양쪽 모두 악마 세계관이지만, **아군은 미형 인간형 / 적은 괴물형**으로 시각적 대비 확보.

## 4. 능력치(스탯) 시스템

### 기본 능력치 5종 (B안: 1스탯 = 1역할)

| 능력치 | 약칭 | **단일 역할** | 비고 |
|--------|------|-------------|------|
| **힘(Strength)** | STR | 물리 공격력 | 물리 딜러 핵심 |
| **민첩(Dexterity)** | DEX | 공격속도 | 행동 게이지 충전 속도 |
| **체력(Vitality)** | VIT | HP + 방어력 | 탱커/생존 핵심 |
| **운(Luck)** | LCK | 치명타 확률 | 확률형 딜 극대화 |
| **지능(Intelligence)** | INT | 마법 공격력 | 마법 딜러 핵심 |

> **명중/회피 삭제**: 자동전투에서 "빗나감"은 답답함만 유발. 모든 공격은 100% 명중.
> **마나 없음**: 스킬은 쿨다운(타이머)으로만 제한. 전투 중 자원 관리 불필요.

### 스탯 공식

| 세부 스탯 | 공식 | 담당 스탯 |
|-----------|------|----------|
| 물리 공격력 (ATK) | `(STR×2 + 무기dmg) × (1 + STR×0.005) × 등급배율` | **STR** |
| 마법 공격력 (MATK) | `(INT×2) × (1 + INT×0.005) × 등급배율` | **INT** |
| 최대 HP | `(100 + VIT×10) × 등급배율` | **VIT** |
| 방어력 (DEF) | `(VIT×0.5 + 방어구DEF) × 등급배율` | **VIT** |
| 행동 게이지 충전 | `기본속도(10) + DEX × 0.3` | **DEX** |
| 치명타 확률 (%) | `LCK × 0.5` (최대 80%) | **LCK** |
| 치명타 데미지 | `×1.5` (고정, 아이템으로 증가 가능) | - |
| 방어 감소율 | `DEF / (DEF + 100)` (수확체감) | **VIT** |
| 최종 공격력 | `max(ATK, MATK)` | STR or INT |

### 등급 배율

| 등급 | 배율 |
|------|------|
| common | ×1.0 |
| uncommon | ×1.15 |
| rare | ×1.3 |
| legendary | ×1.5 |

### 스탯 투자 방식

- **바알**: 지휘관 (전투 참여 안 함). 레벨업 시 지휘관 버프 자동 강화.
- **영웅**: hero_base.csv의 고정 베이스 + 레벨 보정. 스탯 직접 투자 불가.
- **최대 레벨**: 50
- **스탯 리셋**: 골드 지불 (`레벨 × 500 골드`)

### 데미지 공식

```
최종 데미지 = max(1, ATK × 스킬배율 - 적DEF) × 치명타배율(발동 시) × (1 - 피해감소%)

- ATK = max(물리ATK, 마법MATK)
- 스킬배율: 일반공격 ×1.0 / 액티브 스킬 ×2.0
- 치명타배율: 발동 시 ×1.5
```

### 유효체력(EHP)

```
EHP = HP × (100 + DEF) / 100
```

DEF 100당 HP만큼의 유효체력 증가.

## 5. 전투 시스템

### 기본 구조

- **3인 파티 자동전투**: 바알(슬롯1) + 용병 2명 vs 적 3마리
- **행동 게이지 기반**: 각 유닛의 speed에 비례하여 게이지 충전
- **게이지 100% → 행동**: 가장 빨리 찬 유닛이 먼저 행동
- **서버 시뮬레이션**: 서버에서 전투 결과를 계산, 클라이언트에서 재생

### 행동 게이지 시스템

```
행동 게이지 충전 = 기본속도(10) + DEX × 0.3
게이지가 100에 도달한 유닛이 행동
행동 후 게이지 = 0으로 리셋
```

> DEX가 높을수록 더 자주 행동. DEX 30이면 speed 19, DEX 50이면 speed 25.

### 전투 진행

```
스테이지 입장 → 적 3마리 등장
    ↓
모든 유닛 게이지 동시 충전 (speed 비례)
    ↓
게이지 100% 도달 유닛 → 행동 (기본공격 or 액티브 스킬)
    ↓
적 전멸 → 드롭 획득 → 다음 웨이브 or 클리어
    ↓
아군 전멸 → 패배 → 마을 귀환
```

### 전투 설정 (전투 전 전략)

| 설정 항목 | 설명 |
|----------|------|
| **스킬 우선순위** | 액티브 스킬 사용 순서 |
| **타겟 우선순위** | HP 낮은 적 / 뒤열 / 앞열 등 |
| **포션 사용 조건** | HP N% 이하 시 자동 사용 |

### 액티브 스킬 발동 (B안: 스킬 타이머 방식)

- 각 영웅은 고유 액티브 스킬 1개 보유
- **스킬 게이지**: 행동 게이지와 별도로, speed에 비례하여 동시 충전
- **발동 조건**: 스킬 게이지 100% + 다음 행동 시 → 일반 공격 대신 스킬 발동
- **스킬 게이지 max**: 기본 12.0 (hero_base.csv에서 영웅별 설정 가능)
- 스킬 데미지 = 기본 공격력 × 2.0 (스킬 배율)

```
[행동 게이지] ████████████ 100% → 공격!
[스킬 게이지] ██████░░░░░░  60% → 아직...

[행동 게이지] ████████████ 100% → 공격!
[스킬 게이지] ████████████ 100% → ★스킬 발동!★ (일반 공격 대신)
```

### 상태이상 4종 (현재 구현)

| 상태이상 | 효과 | 지속 | 챕터 |
|---------|------|------|------|
| 🔥 화상 (burn) | 매 턴 최대HP 5% 데미지 | 3턴 | Ch1 분노 |
| ❄️ 동결 (freeze) | 행동 불가 (게이지 충전 정지) | 2턴 | Ch4 나태 |
| ☠️ 독 (poison) | 매 턴 최대HP 5% 데미지 | 3턴 | Ch2 질투 |
| 💜 매혹 (charm) | 같은 편 공격 | 2턴 | Ch6 색욕 |

**규칙:**
- 같은 상태이상 중복 시 타이머 갱신
- 다른 종류는 동시 적용 가능
- 액티브 스킬 발동 시 확률적으로 부여 (영웅별 고정)

### 전투 보상

| 요소 | 보상 |
|------|------|
| 일반 몬스터 처치 | 골드 + 경험치 + 일반 아이템 |
| 정예 몬스터 처치 | 골드 + 경험치 + 고급 아이템 |
| 스테이지 보스 처치 | 골드 + 경험치 + 희귀 아이템 |
| 챕터 보스 처치 | 전설 아이템 + 다음 챕터 해금 |

### 사망 및 패배

- **파티 전멸 시**: 마을 귀환, 획득 아이템 유지
- **경험치 패널티**: 현재 레벨 경험치의 10% 차감 (레벨다운 없음)
- **클리어한 스테이지 재진입 가능** (파밍)

## 6. 영웅(용병) 시스템

### 영웅 등급

영웅 등급은 **영입 시 랜덤** 결정. 등급에 따라 접사 스킬 슬롯 수가 달라짐.

| 등급 | 색상 | 접사 슬롯 | 설명 |
|------|------|----------|------|
| **Normal** | 흰색 | 0 | 메인 스킬만 |
| **Magic** | 파란색 | 1 | 접사 스킬 1개 |
| **Rare** | 노란색 | 2 | 접사 스킬 2개 |
| **Unique** | 금색 | 1 + 고유 강화 1 | 접사 1개 + 고유 스킬 강화 |

### 영웅 구조

각 영웅은 다음 요소로 구성:

| 요소 | 내용 | 결정 시점 |
|------|------|----------|
| hero_id | 고유 식별자 | 고정 |
| 베이스 스탯 | STR/DEX/VIT/LCK/INT | 고정 (hero_base.csv) |
| 고유 패시브 | 전투 시 자동 발동 | 고정 |
| 메인 스킬 | 고유 액티브 스킬 | 고정 |
| 등급 (grade) | normal/magic/rare/unique | 영입 시 랜덤 |
| 접사 스킬 | 7죄종 접사 기반 추가 스킬 | 영입 시 랜덤 |
| 전직 | 5직업 중 택1 | 유저 선택 |
| 죄종 | 7죄종 중 택1 → 특성풀 개방 | 전직 시 유저 선택 |

- **레벨**: 전투 참여 시 경험치 획득 → 레벨업

### 선술집 — 영웅 영입

> 영웅들이 주기적으로 찾아오는 선술집. 빈 자리가 생기면 일정 시간 후 새 영웅이 도착한다.

**좌석 시스템 (3석)**

```
선술집 (3석)
┌──────────┬──────────┬──────────┐
│  Slot 1  │  Slot 2  │  Slot 3  │
│ 사탄     │ (빈 자리)│ 유키온나  │
│ Rare     │ 32분 후  │ Common   │
│ 잔여 45분│ 도착예정 │ 잔여 1시간│
└──────────┴──────────┴──────────┘
```

**시간 설계**

| 파라미터 | 값 | 의도 |
|---------|-----|------|
| 도착 쿨타임 | 60분 | 하루 접속 시 자연스러운 로테이션 |
| 체류 — Common | 180분 | 넉넉히 고민 가능 |
| 체류 — Uncommon | 120분 | 표준 |
| 체류 — Rare | 60분 | 빨리 결정 |
| 체류 — Legendary | 30분 | 놓치면 아쉬운 긴박감 |

**등급 확률 및 영입 비용**

| 등급 | 확률 | 영입 비용 |
|------|------|----------|
| Common | 50% | 500G |
| Uncommon | 30% | 2,000G |
| Rare | 15% | 8,000G |
| Legendary | 5% | 30,000G |

**규칙**
- 이미 보유한 영웅은 나타나지 않음
- 등급(Normal/Magic/Rare/Unique)은 영입 시 랜덤 결정
- 등급에 따라 접사 스킬 슬롯 수 결정
- 28체 영웅 모두 보유 시 아무도 오지 않음

## 7. 장비 시스템

### 장비 슬롯 — 3슬롯 자유장착

3개 슬롯에 무기/갑옷/기타 구분 없이 자유롭게 장착. 직업 제한 없음.

```
영웅 장비 (3슬롯 자유장착)
┌──────────┬──────────┬──────────┐
│  Slot 1  │  Slot 2  │  Slot 3  │
│  자유    │  자유    │  자유    │
└──────────┴──────────┴──────────┘

장비 카테고리:
├── 무기 (공격력)
├── 갑옷 (방어력/체력)
└── 기타 (장갑/신발/장신구 — 유틸)
```

**중복 제한**: 유니크 등급은 같은 아이템 1개만 장착 가능. 일반~레어는 중복 가능.

**빌드 예시**:
- 무기3: 극딜 유리캐논
- 무기2 + 갑옷1: 표준 딜러
- 무기1 + 갑옷1 + 기타1: 균형형
- 갑옷2 + 무기1: 브루저
- 갑옷3: 극탱

### 무기 — 15종 (5분류 × 빠름/중간/느림)

각 무기는 공속/데미지 3단계 + 고유 Implicit 보유. 직업 제한 없음.

**검류 (3종)**

| **대검** | 느림 | 높음 | 방어력 20% 무시 |

**찌르기/찍기류 (3종)**

| 무기 | 속도 | 데미지 | Implicit |
|------|------|--------|---------|
| **창** | 빠름 | 낮음 | 선제 1타 (전투 시작 시 즉시 공격) |
| **도끼** | 중간 | 중간 | 기본 데미지 +30% |
| **둔기** | 느림 | 높음 | 경직 시간 +N초 |

**단검류 (3종)**

| 무기 | 속도 | 데미지 | Implicit |
|------|------|--------|---------|

| **투척단검** | 중간 | 중간 | 후열 직접 공격 가능 |
| **독검** | 느림 | 높음 | 타격 시 중독 부여 (턴당 n% HP) |

| 무기 | 속도 | 데미지 | Implicit |

| **오브** | 느림 | 높음 | 상태이상 지속시간 +1턴 |

**힐러무기류 (3종)**

| 무기 | 속도 | 데미지 | Implicit |
|------|------|--------|---------|
| **성경** | 빠름 | 낮음 | 힐량 +25% |

### 세트 시스템 — 파티 합산

**파티 3영웅의 장비 세트포인트를 합산** → **파티 전원에게 세트 보너스 적용**.

```
세트포인트 계산:
  3영웅 × 3슬롯 × 최대 2pt(레어/크래프트) = 최대 18pt

예시:
  영웅A 장비: 분노2 + 색욕1
  영웅B 장비: 분노2 + 시기2
  영웅C 장비: 색욕2 + 시기1
  ─────────────────────────
  파티 합산: 분노4 / 색욕3 / 시기3
  → 분노 4세트 발동 (파티 전원)
  → 색욕 2세트 발동 (파티 전원)
  → 시기 2세트 발동 (파티 전원)
```

브레이크포인트: **2/4/6**
기본 죄종 +1pt: **삭제** (RPG와 다름)

## 8. 아이템 드롭 시스템

### mlvl 기반 드롭 구조 (디아블로 2 구조)

```
dlvl(던전 레벨) → mlvl(몬스터 레벨) → ilvl(아이템 레벨)

mlvl 보정:
  일반몹      = dlvl
  정예        = dlvl + 2
  스테이지보스 = dlvl + 3
  챕터보스    = 고정값 (cap 50)

ilvl = 드롭한 몬스터의 mlvl
```

### 드롭 종류

| 종류 | 설명 | 드롭 대상 |
|------|------|----------|
| 골드 | 범용 화폐 | 모든 몬스터 |
| 장비 | 무기/갑옷/기타(장갑,신발,장신구) | 정예, 보스 |
| 포션 | 체력 회복 | 모든 몬스터 |
| 광석 | 크래프팅 재료 (향후) | 모든 몬스터 |
| 낙인 | 챕터별 죄종 재료 (향후) | 챕터 보스 (희귀) |

### 스폰 등급별 보상 배율

| 등급 | HP 배율 | ATK 배율 | EXP 배율 | 골드 배율 | 드롭 수 |
|------|---------|---------|---------|---------|---------|
| 일반 | ×1.0 | ×1.0 | ×1.0 | ×1.0 | 1 |
| 정예 | ×3.0 | ×1.5 | ×3.0 | ×2.0 | 2 |
| 스테이지 보스 | ×10.0 | ×2.5 | ×10.0 | ×5.0 | 3 |
| 챕터 보스 | ×20.0 | ×5.0 | ×20.0 | ×10.0 | 5 |

### 장비 드롭 로직

```
1. 몬스터 처치
2. 드롭 여부 결정 (spawn-grade별)
3. 부위 결정 (monster-base별 가중치)
4. 베이스 품질 결정 (베타 분포)
5. 등급 결정 (mlvl 기반 확률)
6. 접두/접미사 결정 (필드 죄종 편향)
7. 공통 옵션 결정 (부위별 풀에서 랜덤)
8. 옵션 수치 결정 (베타 분포)
9. 최종 아이템 생성
```

### 타겟 파밍 3축

| 축 | 결정 요소 | 역할 |
|------|---------|------|
| 지역 → 죄종 편향 | 챕터별 특정 죄종 접사 확률 상승 | "어떤 죄종이 필요하지?" |
| 몬스터 베이스 → 카테고리 편향 | 종족별 장비 카테고리(무기/갑옷/기타) 드롭 가중치 | "어떤 장비가 필요하지?" |
| 챕터 보스 → 낙인 | 보스별 해당 죄종 낙인 드롭 | "크래프팅에 어떤 죄종?" |

## 9. 특성 시스템 (구 스킬트리)

### 구조

- 전직 시 7죄종 중 **1개를 선택** → 해당 죄종의 특성풀 개방
- 레벨업 시 특성 포인트 획득, 유저가 직접 배분
- 리셋: 골드 소모로 초기화 가능
- **28체 영웅 전원 동일한 시스템** (바알 포함)

### 특성 탭 구조

```
영웅 특성
├── [고유 탭] 영웅 고유 특성 (항상 보유, 고정)
└── [죄종 탭] 전직 시 선택한 죄종 특성풀
    ├── 공용 특성 2개 (모든 직업)
    ├── 물리 계열 특성 2개 (전사/기사/암살자)
    └── 마법 계열 특성 2개 (마법사/힐러)
```

### 7죄종 특성 방향

| 죄종 | 방향 | 설명 |
|------|------|------|
| 분노 (Wrath) | 공격 특화 | 주체할 수 없는 분노, 복수와 증오 |
| 나태 (Sloth) | 강옵션 + 패널티 | 흥미 부재, 습관적 무기력 |
| 색욕 (Lust) | 아군 강화 (버프/흡혈) | 힘에 대한 강렬한 열망 |
| 질투 (Envy) | 적 약화/탈취 (디버프) | 타인의 것에 대한 분노와 갈망 |
| 교만 (Pride) | 우월함 과시 | 능력에 대한 도착 |
| 폭식 (Gluttony) | 스택형 스탯 특화 | 지나친 탐닉과 과소비 |
| 탐욕 (Greed) | 확률/운 기반 도박 | 물질 소유 추구 |

### 세트와의 관계

- **세트** = 장비로 맞추는 것 (파밍 의존)
- **특성** = 포인트로 찍는 것 (선택 의존)
- **접사 스킬** = 영입 시 랜덤 결정 (등급 의존)
- 같은 죄종 세트 + 특성 = 특화 빌드
- 다른 죄종 혼합 = 하이브리드 빌드

## 10. 챕터 및 던전 구조

### 7챕터 구조

| 챕터 | 죄악 | 배경 | 챕터 보스 | 성경 모티프 |
|------|------|------|----------|-----------|
| **1장** | 분노 | 불타는 전장 | **사탄** | 카인과 아벨 |
| **2장** | 질투 | 뒤틀린 숲 | **레비아탄** | 요셉과 형제들 |
| **3장** | 탐욕 | 황금 사막 | **마몬** | 유다의 배신 |
| **4장** | 나태 | 망각의 동토 | **벨페고르** | 요나의 도주 |
| **5장** | 폭식 | 심연의 동굴 | **벨제붑** | 에서의 장자권 |
| **6장** | 색욕 | 타락한 궁전 | **아스모데우스** | 삼손과 데릴라 |
| **7장** | 교만 | 천상의 폐허 | **루시퍼** | 바벨탑 + 루시퍼의 추락 |

### 스테이지 구조

- **7챕터 × 3스테이지 + 챕터 보스** = 28개 보스
- 각 스테이지: [일반3 + 정예1] × 3웨이브 + 보스 (웨이브4) = 13마리
- 3스테이지 클리어 → 챕터 보스 해금
- 챕터 보스 클리어 → 다음 챕터 해금

### 스테이지 런 방식

```
마을 → 스테이지 선택 → 입장 → 웨이브1~3 → 웨이브4(보스) → 마을 귀환 → 드롭 확인
```

- 웨이브 클리어마다 체크포인트 저장
- 귀환/사망 시: 현재 웨이브 처음부터 재시작
- 클리어한 스테이지 재진입 가능 (파밍)

### 챕터별 상세

#### 1장: 분노 — 불타는 전장

| 스테이지 | 이름 | 일반 적 | 스테이지 보스 |
|----------|------|---------|-------------|
| 1-1 | 전초 기지 | 고블린 정찰병, 고블린 전사, 오크 전사 | **아바돈** |
| 1-2 | 전쟁터 한복판 | 인간 보병, 인간 창병, 트롤 돌격병 | **레기온** |
| 1-3 | 죽은 자의 묘지 | 스켈레톤 전사, 스켈레톤 궁수, 스켈레톤 기사 | **둘라한** |
| BOSS | 분노의 문 | 오크 근위, 임프 마법사 | **몰록** |
