## 1. 게임 개요

- **장르**: 웹 RPG (아이템 파밍 + 동료 육성)
- **배경**: Aurea — 신이 걸었던 땅, 7대 죄악이 지배하는 세계
- **핵심 재미**: 동료 육성 + 아이템 파밍 + 용병(악마 고용) 조합 전략
- **컨셉**: "타락한 왕이 인간의 몸으로 7대 죄악을 정복하고, 배신의 진실을 밝힌다"
- **플랫폼**: 웹 브라우저 (PC)
- **참고 게임**: 아포칼립스 (동양온라인, 2010)

### 핵심 루프

```
[사냥] 전장(던전) 입장 → 자동 전투 → 아이템/경험치 획득
    ↓
[성장] 장비 강화 / 능력치 투자 / 스킬 배분
    ↓
[전략] 용병 고용 → 3인 파티 조합
    ↓
[도전] 다음 전장 / 투기장 / 보스전
    ↓
[판단] 실패 시 → 장비 파밍 / 스탯 재배분 / 용병 교체
    ↓
반복
```

### 아포칼립스 원작 대비 차별점

| 항목 | 아포칼립스 (원작) | TheSevenRPG (본 기획) |
|------|-------------------|------------------------|
| 세계관 | 판타지 (디아블로풍) | 7대 죄악 (성경 모티프 + 다크 판타지) |
| 직업 | 마법사/기사/투사/도적/성직자 | 전사/수호자/마법사/암살자/사제 |
| 용병 정체성 | 익명의 유저 캐릭터 | 악마/보스 캐릭터 (사탄, 레비아탄 등) |
| 던전 | 판타지 던전 | 7대 죄악 영역 (불타는 전장, 뒤틀린 숲 등) |
| 아이템 | 일반 판타지 장비 | 죄악 명물 (카인의 검, 바벨의 왕관 등) |
| 보스 | 판타지 몬스터 | 7대 죄악 마왕 (사탄, 레비아탄, 마몬 등) |
| 세력전 | 공성전 (길드) | 천상/지옥/인간계 3세력 쟁패전 |

## 2. 세계관 및 스토리

### 세계 배경 — Aurea (아우레아)

태초에 하나의 신이 세계를 창조하고, 자신을 7개의 감정으로 나누어 세계의 균형 장치로 심었다:
**분노(Wrath), 나태(Sloth), 탐욕(Greed), 질투(Envy), 폭식(Gluttony), 색욕(Lust), 교만(Pride).**

그러나 인간은 이 죄악을 관리하는 대신 **소유하려** 했다.
균형이 무너졌다. 신은 쓰러졌다. 7개의 감정은 세계 곳곳에 흩어진 **타락한 죄악의 화신**이 되어, 각 지역을 자신의 색으로 물들였다.

### 플레이어 — 바알(Baal), 낙인을 품은 자

플레이어는 **바알**, 한때 마왕이었던 존재다.

바알은 자신의 7가지 감정을 7명의 하인에게 나누어 지옥의 균형을 유지했다.
그러나 어느 밤, **배신의 밤** — 7자루의 칼이 바알의 등을 찔렀다.
힘은 빼앗기고, 기억은 흐려지고, 바알은 인간의 몸으로 떨어졌다.

한 노인이 물을 건넸다. 인간들은 낯선 자를 위해 음식을 나누고 상처를 감쌌다.
바알은 이해할 수 없었다 — 지옥에서는 쓰러진 자를 밟고 지나갈 뿐이었다.

그날 밤, 수평선이 붉게 타올랐다. 사탄의 군대. 마을이 불탔다. 바알은 일어섰다.
마을을 지키기 위해서가 아니라, 적이 자신을 죽이러 왔으니까. **아니면 그렇게 생각했을 뿐이거나.**

### 스토리 진행 방식

- **챕터 기반 진행**: 7대 죄악을 하나씩 정복하며 배신의 진실에 다가감
- **플레이어 = 타락한 마왕**: 인간의 몸으로 잃어버린 힘을 되찾아가는 여정
- **동료 영입**: 챕터 보스 클리어 시 해당 악마와의 인연 → 용병으로 고용 가능
- **성경 모티프**: 각 챕터가 성경의 이야기와 대응 (카인과 아벨, 요셉과 형제들, 유다의 배신 등)

### 배신의 밤 — 진실의 구조

플레이어가 챕터를 진행하며 밝혀내는 핵심 서사:

```
[대천사 티리엘] → 모든 배신을 설계한 흑막
    ↓
[벨제붑] → 충동적으로 서약(Covenant)을 넘겨줌 (문을 연 자)
    ↓
[레비아탄] → "죽이지 마라, 모든 것을 빼앗고 아무것도 아닌 것으로 떨어뜨려라"
    ↓
[마몬] → 거래를 성사시킴 (대가를 받은 자)
    ↓
[벨페고르] → 알고 있었지만 침묵 (방관한 자)
    ↓
[아스모데우스] → 처음부터 티리엘의 첩자 (약점을 제공한 자)
    ↓
[사탄] → 이미 추방된 상태, 배신과 무관하게 독자적으로 추격
    ↓
[루시퍼] → 배신하지 않았다. 바알을 살리기 위해 "죽이지 않는 추락"을 유도
```

### 주요 인물 (NPC)

| 인물 | 역할 | 거점 위치 |
|------|------|----------|
| 노인 (인간) | 치유사 — 회복/부활 서비스 | 객잔 |
| 마몬의 대리인 | 암시장 상인 | 암시장 |
| 벨페고르의 환영 | 전략 조언 — 퀘스트 안내 | 서재 |
| 메피스토펠레스 | 용병 소개 — 용병 길드 운영 | 계약의 전당 |
| 다곤 | 대장장이 — 무기/방어구 강화 | 대장간 |
| 나르키소스 | 점술사 — 스탯 리셋/재배분 | 거울의 방 |

## 3. 직업 시스템

> 아포칼립스의 5직업을 TheSevenRPG 세계관에 맞게 변환

### 5직업

| 직업 | 원작 대응 | 역할 | 주요 스탯 | 특징 |
|------|----------|------|----------|------|
| **전사(Warrior)** | 투사 | 근접 딜러 | 힘 + 체력 | 높은 공격력과 적당한 맷집, 강력한 버프 보유 |
| **수호자(Guardian)** | 기사 | 탱커 | 체력 + 힘 | 높은 체력/방어력, 아군 보호 능력 |
| **마법사(Mage)** | 마법사 | 원거리 딜러 | 지능 + 의지 | 죄악 마법 기반 광역/고데미지 |
| **암살자(Assassin)** | 도적 | 암살/교란 | 민첩 + 힘 | 빠른 행동력, 높은 치명타, 적 둔화 |
| **사제(Priest)** | 성직자 | 힐러/버퍼 | 지능 + 체력 | 아군 회복/부활, 상태이상 해제 |

### 파티 구성 제약

- **파티 최대 3인** (본캐 1 + 용병 2)
- 같은 직업 중복 가능 (전사 3인 파티 등)
- 권장 조합: 수호자(탱커) + 딜러(전사/마법사/암살자) + 사제(힐러)
- 비권장이지만 가능한 극단 조합도 허용 → 유저 자유도 보장

### 아포칼립스 원작의 문제점 보완

> 원작 리뷰에서 지적된 "성직자+기사 필수, 나머지는 딜러만" 문제

**보완 방안:**
- 사제 없이도 생존 가능하도록 **포션 시스템** 보강
- 수호자 없이도 가능하도록 **회피/흡혈** 빌드 허용
- 직업별 자체 생존기 1개씩 부여 (전사=흡혈타, 마법사=은신, 암살자=회피폭발)
- 파티 조합 보너스로 비정석 조합도 보상

## 4. 능력치(스탯) 시스템

> 아포칼립스의 4스탯(힘/민첩/체력/지능)을 TheSevenRPG 세계관에 맞게 변환

### 기본 능력치 5종

| 능력치 | 원작 대응 | 효과 |
|--------|----------|------|
| **힘(Strength)** | 힘 | 물리 공격력 증가, 물리 방어 관통 |
| **지능(Intelligence)** | 지능 | 마법 공격력 증가, 마나 증가 |
| **민첩(Agility)** | 민첩 | 행동력 회복 속도, 명중률, 회피율 |
| **체력(Vitality)** | 체력 | 최대 생명력 (1포인트당 +5 HP), 물리 방어력 |
| **의지(Will)** | 신규 추가 | 용병 버프 효과, 파티 시너지 강화, 죄악 저항력 |

### 스탯 투자 방식

- **레벨업**: 레벨당 스탯 포인트 5점 획득
- **골드 투자**: 골드로 추가 스탯 포인트 구매 가능 (아포칼립스 원작 시스템 계승)
  - 비용: `현재 총 스탯 × 100 골드` (점점 비싸짐)
  - 상한: 레벨당 최대 골드 투자 포인트 제한 (골드만으로 무한 성장 방지)
- **스탯 리셋**: 나르키소스(거울의 방 NPC)에게 골드 지불하여 재배분
  - 비용: `레벨 × 500 골드`

### 의지 스탯의 역할 (신규)

> "잃어버린 힘을 되찾고 하인들을 다시 이끄는 마왕"을 게임 시스템으로 구현

- 의지 1포인트당:
  - 용병(고용 악마)의 전투력 +0.5% 보정
  - 파티 조합 보너스 효과 +1% 강화
  - 용병 고용 비용 -0.3% 감소
  - 죄악 상태이상 저항 +0.5%
- 의지가 높으면 → "하인을 지배하는 마왕" 느낌
- 의지 최소 투자 시 → 본캐 혼자 강한 "단독 전투 특화" 빌드

## 5. 전투 시스템

> 아포칼립스의 자동 전투 시스템을 계승하되 전략성 강화

### 기본 구조

- **자동 전투**: 전투 시작 후 캐릭터가 자동으로 공격/스킬 사용
- **행동력 기반 턴제**: 민첩(행동력 회복 속도)에 따라 행동 순서 결정
- **파티 단위 전투**: 3인 파티 vs 적 다수

### 전투 진행

```
전장 입장 → 적 조우 → 자동 전투 개시
    ↓
행동력 순서대로 아군/적 번갈아 행동
    ↓
스킬 우선순위: 사전 설정한 스킬 순서대로 자동 사용
    ↓
적 전멸 → 드롭 획득 → 다음 적 조우 or 전장 클리어
```

### 전투 설정 (전투 전 전략)

> 원작의 "전투 중 전략 수립" 개념을 발전

플레이어가 전투 전에 설정하는 항목:

| 설정 항목 | 설명 |
|----------|------|
| **스킬 우선순위** | 스킬 사용 순서 지정 (1~4순위) |
| **타겟 우선순위** | 적 중 누구를 먼저 공격할지 (HP낮은적/뒤열/앞열 등) |
| **포션 사용 조건** | HP가 몇 % 이하일 때 포션 자동 사용 |
| **진형 배치** | 전열(탱커)/중열(딜러)/후열(힐러) 배치 |

### 행동력 시스템

- 기본 행동력: 100
- 행동 소모: 일반 공격 100, 스킬 80~150 (스킬마다 다름)
- 회복 속도: 기본 10/초 + 민첩 × 0.3/초
- **행동력이 빨리 차는 캐릭터가 먼저 행동** → 민첩의 가치 = 아포칼립스 원작과 동일

### 전투 보상

| 요소 | 보상 |
|------|------|
| 일반 몬스터 처치 | 골드 + 경험치 + 일반 아이템 |
| 정예 몬스터 처치 | 골드 + 경험치 + 고급 아이템 |
| 스테이지 보스 처치 | 골드 + 경험치 + 희귀 아이템 + 악마 인연 |
| 챕터 보스 처치 | 전설 아이템 + 신규 악마 해금 + 다음 챕터 해금 |

### 사망 및 패배

- **사망 시**: 해당 전장 입구로 귀환, 획득 아이템 유지
- **경험치 패널티**: 현재 레벨 경험치의 10% 차감 (레벨다운 없음)
- **파티 전멸 시**: 전장 밖으로 강제 귀환

## 6. 영웅(악마) 시스템

> 7대 죄악의 마왕과 그 하수인들 — 강렬한 캐릭터성을 가진 동료 시스템

### 악마 등급

| 등급 | 색상 | 설명 | 예시 |
|------|------|------|------|
| **전설(Legendary)** | 금색 | 7대 죄악의 마왕, 고유 스킬 보유 | 사탄, 레비아탄, 마몬, 루시퍼 |
| **상급(Epic)** | 보라색 | 마왕의 직속 부하, 직업 특화 스킬 | 몰록, 나르키소스, 메피스토펠레스, 아스타로트 |
| **중급(Rare)** | 파란색 | 중견 악마, 기본 스킬 | 레기온, 둘라한, 아비주, 파주주 |
| **하급(Common)** | 녹색 | 일반 악마 | 아바돈, 다곤, 카론, 유키온나 |

### 악마 해금 방식

- **챕터 클리어**: 해당 챕터 보스전 관련 악마 해금 (인연 시스템)
- **투기장 보상**: 높은 등급 달성 시 특정 악마 해금
- **퀘스트 완료**: 특정 연쇄 퀘스트 완료 시 악마 해금
- **암시장 교역**: 희귀 악마 계약서 구매 (매우 고가)

### 시설별 상세

#### 선술집 — "떠돌이들의 객잔"

> 영웅들이 주기적으로 찾아오는 선술집. 빈 자리가 생기면 일정 시간 후 새 영웅이 도착한다.
> 플레이어가 접속하지 않아도 영웅은 오고 간다.

**좌석 시스템 (3석)**

```
선술집 (3석)
┌──────────┬──────────┬──────────┐
│  Slot 1  │  Slot 2  │  Slot 3  │
│ 사탄     │ (빈 자리)│ 유키온나  │
│ Rare     │ 32분 후  │ Common   │
│ 잔여 45분│ 도착예정 │ 잔여 1시간│
└──────────┴──────────┴──────────┘
```

- 게임 시작 시 3석 모두 비어있고, 각각 쿨타임 후 순차 도착
- 초기 쿨타임: Slot1 즉시 / Slot2 +30분 / Slot3 +60분

**시간 설계**

| 파라미터 | 값 | 의도 |
|---------|-----|------|
| 도착 쿨타임 (빈 자리→새 영웅) | 60분 | 하루 접속 시 자연스러운 로테이션 |
| 체류 시간 — Common | 180분 (3시간) | 넉넉히 고민 가능 |
| 체류 시간 — Uncommon | 120분 (2시간) | 표준 |
| 체류 시간 — Rare | 60분 (1시간) | 희소성 → 빨리 결정해야 하는 긴장감 |
| 체류 시간 — Legendary | 30분 | 놓치면 아쉬운 긴박감 |

**등급 확률 및 영입 비용**

| 등급 | 확률 | 영입 비용 |
|------|------|----------|
| Common (일반) | 50% | 500G |
| Uncommon (고급) | 30% | 2,000G |
| Rare (희귀) | 15% | 8,000G |
| Legendary (전설) | 5% | 30,000G |

**진영 확률**

| 진영 | 확률 |
|------|------|
| Human (인간) | 40% |
| Demon (악마) | 40% |
| Celestial (천상) | 20% |

**영웅 풀 및 중복 규칙**

- 바알(본캐)은 선술집에 나타나지 않음
- 이미 보유한 영웅은 선술집에 나타나지 않음
- 현재 선술집에 앉아있는 영웅과 같은 영웅은 다른 슬롯에 배치하지 않음
- 영웅당 스킬트리 2개는 7죄종 중 랜덤 배정
- 27체 영웅을 모두 보유하면 선술집에 아무도 오지 않음 (컴플리트 상태)

**조회 로직**

```
선술집 진입 시 3개 슬롯 조회:
  ├─ 영웅 있음 + 만료 안 됨 → 그대로 표시
  ├─ 영웅 있음 + 만료됨 → 정리, next_arrival_at = now + 60분
  └─ 영웅 없음
      ├─ next_arrival_at 경과 → 새 영웅 생성
      └─ next_arrival_at 미경과 → "N분 후 도착" 표시
```

**플레이어 액션**

| 액션 | 설명 |
|------|------|
| 영입 | 골드 지불 → 영웅 보유 목록에 추가 → 해당 슬롯 비움 → 60분 후 새 영웅 도착 |
| 돌려보내기 | 즉시 퇴장 → 해당 슬롯 비움 → 60분 후 새 영웅 도착 |
| 방치 | 체류 시간 만료 시 자동 퇴장 → 60분 후 새 영웅 도착 |

**선택적 확장 (추후 논의)**

| 요소 | 설명 | 우선순위 |
|------|------|---------|
| 술 한 잔 대접 | 소량 골드로 체류 시간 30분 연장 (1회 한정) | 중 |
| 소문 듣기 | 빈 슬롯의 다음 영웅 진영을 미리 알려줌 (비용: 200G) | 낮 |
| 객잔 확장 | 게임 후반 4번째 슬롯 해금 (챕터3 클리어 조건) | 낮 |
| 진영 이벤트 | 특정 요일에 특정 진영 확률 UP (화: 악마 60%) | 낮 |

#### 다곤의 대장간

| 기능 | 설명 | 재료 |
|------|------|------|
| **제작** | 설계도 + 재료 → 장비 생성 | 마석 + 골드 + 설계도 |

#### 연옥 (훈련소)

- 골드를 소모하여 경험치 획득
- 시간 기반: 훈련 시간 설정 → 시간 경과 후 경험치 수령
- 오프라인 훈련 가능 (접속하지 않아도 경험치 누적)
- 비용: `레벨 × 100 골드 / 시간`

#### 투기의 원형경기장 (투기장)

> 아포칼립스 원작의 "보상 부족" 문제 보완

- **등급제**: 동/은/금/백금/전설 5단계
- **시즌제**: 1시즌 = 1주일, 시즌 종료 시 등급별 보상
- **보상 강화**:
  - 일일 도전 보상 (매일 3회 무료 대전 → 승리 시 보상)
  - 시즌 종료 보상 (등급별 장비/재화/악마 계약서)
  - 연승 보너스 (3연승/5연승/10연승 추가 보상)

### 스테이지 구조

각 챕터 = 3개 일반 스테이지 + 1개 보스 스테이지

```
챕터 N
  ├── 스테이지 1: 외곽 탐색 (일반 몬스터 + 스테이지 보스 1)
  ├── 스테이지 2: 내부 침투 (일반 몬스터 + 스테이지 보스 2)
  ├── 스테이지 3: 핵심부 돌파 (일반 몬스터 + 스테이지 보스 3)
  └── 보스 스테이지: 챕터 보스전
```

### 스테이지별 적 구성

- **일반 몬스터**: 해당 지역 테마에 맞는 유닛 (3~5마리/웨이브)
- **스테이지 보스**: 이름 있는 악마/언데드 (웨이브당 1마리, 높은 능력치)
- **웨이브 구조**: [일반 3~5] × 3웨이브 + 스테이지 보스 1 (스테이지당 4웨이브)
- **보스 스테이지**: 일반 웨이브 2회 + 스테이지 보스 1회 + 챕터 보스 1회

### 챕터별 상세

#### 1장: 분노(Wrath) — 불타는 전장

> 사탄의 분노가 대지에 스며들어 끝없는 전쟁이 벌어지는 황폐한 전장.
> 바알은 여기서 분노가 만들어내는 파괴의 네 가지 형태를 목격한다.

| 스테이지 | 이름 | 배경 | 일반 적 | 스테이지 보스 |
|----------|------|------|---------|-------------|
| 1-1 | 전초 기지 | 불타는 초원 | 고블린 정찰병, 고블린 전사, 오크 전사 | **아바돈(파괴왕)** — 오크 기반, 악마형 |
| 1-2 | 전쟁터 한복판 | 전쟁의 폐허 | 인간 보병, 인간 창병, 트롤 돌격병 | **레기온(천의 목소리)** — 인간 기반, 일반형 |
| 1-3 | 죽은 자의 묘지 | 뼈가 쌓인 묘지 | 스켈레톤 전사, 스켈레톤 궁수, 스켈레톤 기사 | **둘라한(머리 없는 전쟁 유령)** — 스켈레톤 기반, 언데드형 |
| BOSS | 분노의 문 | 화염 관문 | 오크 근위, 임프 마법사 | **몰록(화염의 신도)** — 가고일 기반, 악마형 |

**아바돈 — 파괴의 왕:**
사탄의 충실한 추종자. "눈앞의 것을 파괴하라"는 명령을 받고 자기 자신을 잃었다. 이제 파괴만이 남았다.
*분노의 형태: 방향 없는 맹진. 분노 그 자체가 방향이 된 존재.*

**레기온 — 천의 목소리:**
사탄의 거짓 약속에 속은 인간 장군. "나와 함께하면 병사들을 지켜주마." 병사들은 죽었고, 복수의 영혼이 장군의 몸에 합쳐졌다. "우리는 많으니 군단이라 하라."
*분노의 형태: 자기 자신을 향한 분노. 만 가지 비명이 안으로 돌아간다.*

**둘라한 — 머리 없는 전쟁 유령:**
사탄이 오기 훨씬 전에 이곳에 묻힌 기사. 분노가 대지에 스며들자 죽은 자가 깨어났다. 원한도, 선택도 없이 그저 깨어났을 뿐. 자신이 누구였는지조차 기억나지 않는다.
*분노의 형태: 목적 없는 분노. 정체성마저 삼켜버린 가장 위험한 형태.*

**몰록 — 화염의 신도:**
자발적으로 사탄을 따른 유일한 추종자. 명령이 아닌 선택. 사탄의 허락 없이는 누구도 통과시키지 않는 관문의 수호자.
*분노의 형태: 헌신적 분노. 분노 자체가 신앙이 된 존재.*

**사탄 보스 패턴:**
- 1페이즈: 일반 공격 + 분노의 질주 (단일 고데미지)
- 2페이즈 (HP 50%): 추방자의 각성 → 부하 소환 + 아군 화상
- 3페이즈 (HP 20%): 광란 → 공격력 2배, 방어력 절반, 공격속도 +50%

**1장 드롭 아이템:**
- 일반 몬스터: 동전, 거친 마석, 기본 장비(흰색)
- 스테이지 보스: 고급 장비(녹색), 강화석
- 사탄: 분노의 대검(파란색 전사 무기), 화염 갑옷(파란색 방어구), 악마 계약서: 몰록

#### 2장: 질투(Envy) — 뒤틀린 숲

> 레비아탄의 질투가 숲을 뒤틀었다. 모든 것이 탐하고, 빼앗고, 그래도 채워지지 않는 공간.
> 바알은 여기서 배신자의 이름을 알게 된다 — 이것은 반란이 아니라, 가족 간의 갈등이었다.

| 스테이지 | 이름 | 배경 | 일반 적 | 스테이지 보스 |
|----------|------|------|---------|-------------|
| 2-1 | 독의 길목 | 독안개 숲 입구 | 독 늑대, 리자드맨 주술사, 리자드맨 돌격병 | **사마엘(독의 지배자)** — 악마형 (뱀 형태) |
| 2-2 | 빼앗긴 정원 | 말라버린 정원 | 서큐버스 마녀, 서큐버스 독사, 오크 찬탈자 | **아비주(불모의 어머니)** — 악마형 (서큐버스 형태) |
| 2-3 | 울음의 숲 | 뒤틀린 나무들 | 나무 유령, 통곡의 고스트, 뿌리 좀비 | **밴시(타락한 울음)** — 언데드형 (고스트) |
| BOSS | 빈 거울의 왕좌 | 수정 왕좌 | 서큐버스 근위, 리자드맨 정예 | **나르키소스(뒤틀린 거울)** — 악마형 (변신체) |

**사마엘 — 독의 지배자:**
레비아탄의 가장 충직한 하인이지만, 레비아탄은 그를 본 적이 없다. 힘 있는 자 곁에 서 있으면서도 보이지 않는 고통.
*질투의 형태: 조용한 갈망. 곁에 있지만 인식되지 못하는 아픔.*

**아비주 — 불모의 어머니:**
한때 풍요로운 땅을 다스렸으나, 레비아탄이 숲을 뒤틀자 무시당했다. 빼앗기지 않았다 — 그저 무시당했다. 그래서 다른 것들을 강박적으로 빼앗기 시작했다.
*질투의 형태: 갈망이 행동이 된다. 빼앗는 것 자체가 목적.*

**밴시 — 타락한 울음:**
숲 근처의 인간 여성. 아름다운 자매가 있었다. 마을은 자매만 보았다. 질투하지 않으려 했다. 정말로. 그러나 레비아탄의 영향이 감정을 증폭시켰다. 빼앗는 대신 파괴했다. 자매를. 자기 자신을. 아름다운 모든 것을.
*질투의 형태: 소유할 수 없으면 파괴한다. 빼앗지 못한 것을 부수는 행위.*

**나르키소스 — 뒤틀린 거울:**
레비아탄의 불완전함을 목격한 유일한 존재. 왕좌에 앉아도 채워지지 않는 것을 보았다. 결론: 빼앗는 것이 안 되면, **되어버려라.** 형태, 힘, 존재 자체를 복제한다. 그러나 복제는 원본이 아니다. 복사할수록 자신의 얼굴을 잊는다.
*질투의 최종 형태: 다른 사람이 되어 자기 자신을 완전히 잃는 것.*

#### 7장: 교만(Pride) — 천상의 폐허

> 루시퍼는 배신하지 않았다.
> 이미 늦었다. 벨제붑이 서약을 넘겼고, 판은 기울었다.
> 레비아탄이 "죽이지 말고 떨어뜨려라"고 제안했을 때, 그 선택을 유도한 것이 루시퍼다. 바알을 살리기 위해.
> 그리고 홀로 기다렸다. 천상의 폐허에서. 티리엘을 상대하며.
> 바알이 최종 힘을 되찾으려면 루시퍼를 이겨야 한다. 루시퍼는 그것을 알기에 싸움을 건다.
> **루시퍼의 죄는 배신이 아니다. 교만이다. "나 혼자서 그를 지킬 수 있다."**

| 스테이지 | 이름 | 배경 | 일반 적 | 스테이지 보스 |
|----------|------|------|---------|-------------|
| 7-1 | 무너진 천계 입구 | 부서진 문 | 타락 천사 전사, 빛의 골렘, 천사 스켈레톤 | **세라핌(타락한 불꽃)** — 가고일 기반, 악마형 |
| 7-2 | 바벨의 잔해 | 무너진 탑 | 바벨 골렘, 언어의 유령, 교만의 리치 | **네피림(거인의 후예)** — 골렘 기반, 일반형 |
| 7-3 | 빛의 회랑 | 빛나는 폐허 | 빛의 기사, 천상 뱀파이어, 신성 좀비 | **메타트론(기록자)** — 리치 기반, 언데드형 |
| BOSS | 새벽의 왕좌 | 빛의 왕좌 | 천사 근위, 빛의 골렘 | **루시퍼(새벽의 별)** |

**루시퍼 보스 패턴:**
- 1페이즈: 빛의 검 — 단일 대상 고데미지 + 실명 (명중률 감소)
- 2페이즈 (HP 50%): 새벽의 각성 — 아군 전체 버프 해제 + 자신 전 스탯 30% 증가
- 3페이즈 (HP 20%): 최후의 교만 — "나 혼자면 충분했다" — 공격력 3배, 피격 시 반격 확정

**루시퍼 격파 시 서사:**
> 바알은 마침내 이해한다. 자신은 버림받은 적이 없었다는 것을.
> 가장 충성스러운 하인이 홀로 고통받으며 자신을 지키고 있었다는 것을.
> **처음으로, 바알이 운다.**

### 재도전 파밍

- 클리어한 스테이지는 언제든 재입장 가능
- 재도전 시에도 경험치/골드/아이템 드롭 동일
- 보스 스테이지 재도전: 희귀 아이템/악마 계약서 반복 파밍
