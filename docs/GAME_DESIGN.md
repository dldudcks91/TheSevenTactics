## 1. 게임 개요

- **장르**: 내러티브 전술 RPG (웹)
- **배경**: Aurea — 신이 걸었던 땅, 7대 죄악이 지배하는 다크 판타지 세계
- **핵심 재미**: 선택의 대가 — 내 선택이 영웅의 사기를 바꾸고, 파티 조합의 전략을 바꾼다
- **컨셉**: "타락한 마왕이 인간의 몸으로 7대 죄악을 정복하고, 배신의 진실을 밝힌다"
- **플랫폼**: 웹 브라우저 (PC)
- **참고 게임**: 다키스트 던전 1/2, HoMM3, 삼국지6

### 핵심 루프

```
[선택] 챕터 진행 → 이벤트 선택지 → 죄종별 사기 변동
    ↓
[편성] 사기 상태에 따라 파티 조합 → 선술집에서 영웅 영입
    ↓
[전투] 3인 파티 자동전투 → 사기가 전투에 영향 (스킬 해금 / 명령 불복)
    ↓
[서사] 챕터 보스 대면 → 스토리 진행 → 다음 챕터
    ↓
[판단] 사기 관리 실패 → 파티 재편성 / 행동 방향 수정
    ↓
반복
```

### 핵심 차별점

| 요소 | 전통 RPG | TheSevenTactics |
|------|---------|-----------------|
| 성장 축 | 레벨/장비/스킬트리 | **사기 관리 + 선택의 결과** |
| 파티 편성 기준 | 전투력 최적화 | **죄종 궁합 + 사기 상태** |
| 리플레이 | 엔드게임 파밍 | **7가지 죄종 선택 = 7가지 플레이스루** |
| 영웅 관계 | 없음 | **죄종 관계에 따른 사기 상호작용** |
| 서사 역할 | 배경 장식 | **선택이 게임플레이를 직접 바꿈** |

## 2. 세계관 및 스토리

### 세계 배경 — Aurea (아우레아)

태초에 하나의 신이 세계를 창조하고, 자신을 7개의 감정으로 나누어 세계의 균형 장치로 심었다:
**분노(Wrath), 나태(Sloth), 탐욕(Greed), 시기(Envy), 폭식(Gluttony), 색욕(Lust), 교만(Pride).**

그러나 인간은 이 죄악을 관리하는 대신 **소유하려** 했다.
균형이 무너졌다. 신은 쓰러졌다. 7개의 감정은 세계 곳곳에 흩어진 **타락한 죄악의 화신**이 되어, 각 지역을 자신의 색으로 물들였다.

### 플레이어 — 바알(Baal), 낙인을 품은 자

플레이어는 **바알**, 한때 마왕이었던 존재다.

바알은 자신의 7가지 감정을 7명의 하인에게 나누어 지옥의 균형을 유지했다.
그러나 어느 밤, **배신의 밤** — 7자루의 칼이 바알의 등을 찔렀다.
힘은 빼앗기고, 기억은 흐려지고, 바알은 인간의 몸으로 떨어졌다.

### 스토리 진행

- **챕터 기반 진행**: 7대 죄악을 하나씩 정복하며 배신의 진실에 다가감
- **동료 영입**: 선술집에 찾아오는 악마/인간/천상 존재를 용병으로 고용
- **선택의 결과**: 플레이어의 행동이 영웅들의 사기에 직접 영향

### 배신의 밤 — 진실의 구조

```
[대천사 티리엘] → 모든 배신을 설계한 흑막
    ↓
[벨제붑] → 충동적으로 서약(Covenant)을 넘겨줌
    ↓
[레비아탄] → "죽이지 마라, 모든 것을 빼앗고 아무것도 아닌 것으로 떨어뜨려라"
    ↓
[마몬] → 거래를 성사시킴 (대가를 받은 자)
    ↓
[벨페고르] → 알고 있었지만 침묵 (방관한 자)
    ↓
[아스모데우스] → 처음부터 티리엘의 첩자
    ↓
[사탄] → 이미 추방된 상태, 배신과 무관하게 독자적으로 추격
    ↓
[루시퍼] → 배신하지 않았다. 바알을 살리기 위해 "죽이지 않는 추락"을 유도
```

## 3. 바알의 죄종

### 게임 시작 시 7죄종 중 1개 선택

바알의 과거 — 마왕이었을 때 가장 강했던 감정.
삼국지6의 군주가 "꿈"을 고르는 것과 같다. 이 선택이 전체 플레이스루의 기준축이 된다.

| 죄종 | 의미 | 플레이 성격 |
|------|------|-----------|
| **교만** (Pride) | 내가 옳다 | 혼자 결정, 지배, 타인 무시 |
| **시기** (Envy) | 왜 쟤가 가졌지 | 빼앗기, 비교, 남의 것을 원함 |
| **분노** (Wrath) | 부숴버린다 | 파괴, 보복, 과격한 해결 |
| **나태** (Sloth) | 알 바 아니다 | 방치, 무시, 포기 |
| **탐욕** (Greed) | 더 가져야 한다 | 축적, 거래, 손해 회피 |
| **폭식** (Gluttony) | 지금 당장 쓴다 | 과투자, 낭비, 충동적 사용 |
| **색욕** (Lust) | 이것만은 놓지 않는다 | 애착, 관계 집착, 보호욕 |

### 바알 죄종의 효과

바알의 죄종은 영웅 영입 시 **초기 사기**를 결정한다.

| 바알과의 관계 | 초기 사기 | 의미 |
|-------------|----------|------|
| 같은 죄종 | 70 | 고양 상태. 스킬 1단계 해금으로 시작 |
| 생성 관계 | 60 | 고양 진입. 곧 스킬 해금 가능 |
| 강화 관계 | 55 | 보통 상위 |
| 중립 | 50 | 기본 |
| 대립 관계 | 30 | 불만 상태. 관리 안 하면 명령 불복 |

### 죄종 간 관계 매트릭스 (원전 기반)

```
         교만  시기  분노  나태  탐욕  폭식  색욕
교만      --   생성  강화  대립  강화   .   강화
시기     전제   --   생성   .   강화   .    .
분노     강화  강화   --   대립  강화   .    .
나태     대립   .   대립   --   대립  강화  대립
탐욕     강화  강화  강화  대립   --   대립  강화
폭식      .    .    .   강화  대립   --   생성
색욕     강화   .    .   대립  강화  생성   --
```

관계 유형:
- **생성**: 앞의 죄가 뒤의 죄를 직접 낳음 (가장 강한 시너지)
- **강화**: 합치면 더 위험해짐 (시너지)
- **대립**: 표면적 모순 (갈등)
- **중립(.)**: 직접적 관계 없음
- **전제**: 앞의 죄가 뒤의 죄를 전제함

> 원전 레퍼런스: [docs/reference/seven_sins_lore.md](reference/seven_sins_lore.md)

## 4. 사기 시스템

### 개요

모든 영웅은 개별 **사기(Morale)** 수치를 가진다. 사기는 플레이어의 선택, 파티 조합, 전투 결과에 따라 변동하며, 전투 성능에 직접 영향을 준다.

> 레퍼런스: HoMM3 사기 + 삼국지6 꿈 + DD1 스트레스 + DD2 관계

### 사기 수치

**범위: 0 ~ 100**

| 구간 | 이름 | 효과 |
|------|------|------|
| 80~100 | **충성** | 스킬 2단계 해금 + 연계 스킬 발동 가능 |
| 60~79 | **고양** | 스킬 1단계 해금 + 추가 행동 확률 |
| 40~59 | **보통** | 기본 상태 |
| 20~39 | **불만** | 명령 불복 확률 10% (턴 스킵) |
| 0~19 | **절망** | 명령 불복 확률 25% + 아군 방해 가능 |

### 사기 변동 요인 (3가지)

#### 요인 1: 플레이어 행동 (삼국지6 꿈)

플레이어가 이벤트에서 선택할 때마다, 보유한 모든 영웅이 자기 죄종에 따라 반응한다.

```
예시: 적을 처형함

  사탄(분노):     "좋다."              사기 +10
  레비아탄(시기):  반응 없음             사기 ±0
  벨페고르(나태):  "...굳이?"           사기 -5
  루시퍼(교만):    "그럴 필요까지는..."   사기 -5
```

#### 요인 2: 파티 조합 (HoMM3 진영)

같이 편성된 영웅의 죄종 관계에 따라 매 전투마다 사기 보정.

| 관계 | 사기 변동/전투 | 예시 |
|------|-------------|------|
| 생성 | +5 | 교만+시기: 시너지 |
| 강화 | +3 | 분노+교만: 시너지 |
| 중립 | ±0 | 변동 없음 |
| 대립 | -5 | 분노+나태: 갈등 |

#### 요인 3: 전투 중 이벤트 (DD1/DD2)

| 이벤트 | 사기 변동 |
|--------|----------|
| 아군이 빈사 상태 | 동료 사기 -5 |
| 아군이 적 처치 | 같은 죄종 영웅 사기 +2 |
| 아군 사망 | 전원 사기 -10 |
| 연속 승리 (3회) | 전원 사기 +3 |
| 연속 패배 (3회) | 전원 사기 -5 |

### 사기 설계 원칙

| 원칙 | 근거 |
|------|------|
| 사기는 떨어지기 쉽고 올리기 어렵다 | DD1 (Affliction 75%), 삼국지6 (충성 올리는 직접 수단 없음) |
| 나쁜 결과가 좋은 결과보다 강하다 | HoMM3 (같은 수치면 마이너스 발동률이 2배) |
| 골드로 사기를 살 수 없다 | 삼국지6. 행동과 편성으로만 올림 |
| 파티 조합이 사기의 기본값을 결정한다 | HoMM3 (진영 혼합 페널티) |
| 전투 중에도 사기가 변한다 | DD1/DD2 (스트레스/친밀도 실시간 변동) |

### 바알 지휘관 보정

바알 레벨에 따라 파티 전원의 사기에 고정 보정. 대립 파티도 바알 레벨이 높으면 어느 정도 커버 가능.

| 바알 레벨 | 사기 보정 |
|----------|----------|
| 1~10 | +5 |
| 11~20 | +10 |
| 21~30 | +15 |

## 5. 이벤트 선택지

### 개요

플레이어의 행동이 영웅 사기를 바꾸는 핵심 메카닉. 두 종류가 있다.

### 종류 1: 서사 선택지 (챕터 고정)

각 챕터에 2~3개. 스토리에 직접 연결되는 선택. 첫 플레이 시에만 등장.

```
예시: Ch2 레비아탄의 질문 "한 번이라도 미안했냐?"

  A. 침묵한다       → 교만 영웅 사기↑ / 색욕 영웅 사기↓
  B. "아니"         → 분노 영웅 사기↑ / 나태 영웅 사기↓
  C. "몰랐다"       → 나태 영웅 사기↑ / 교만 영웅 사기↓
```

### 종류 2: 원정 이벤트 (스테이지 중 랜덤)

웨이브 사이에 짧게 나오는 선택지. 다키스트 던전의 큐리오/이벤트와 유사.

```
예시: 보물상자 발견

  A. 연다           → 탐욕↑ / 폭식↓
  B. 부순다         → 분노↑ / 나태↓
  C. 무시한다       → 나태↑ / 탐욕↓
  D. 부하시켜 열게 함 → 교만↑ / 색욕↓
```

### 종류 3: 암묵적 행동 추적

선택지 없이 플레이 패턴 자체를 추적하여 사기에 반영.

**영웅 관리**

| 행동 | 올라가는 죄종 | 내려가는 죄종 |
|------|-------------|-------------|
| 약해서 영웅 해고 | 교만 | 색욕 |
| 더 좋은 영웅 위해 해고 | 시기 | 색욕 |
| 약한 영웅을 계속 유지 | 색욕 | 교만 |
| 영웅 방치 (레벨 안 올림) | 나태 | 분노 |
| 한 영웅에 자원 몰빵 | 폭식 | 탐욕 |
| 위험 전투에 반복 투입 | 분노 | 색욕 |

**자원 관리**

| 행동 | 올라가는 죄종 | 내려가는 죄종 |
|------|-------------|-------------|
| 골드 축적 (안 씀) | 탐욕 | 폭식 |
| 골드 즉시 전부 사용 | 폭식 | 탐욕 |
| 장비 안 버리고 쌓아둠 | 탐욕 | 폭식 |
| 포션 아끼다 전멸 | 탐욕 | 폭식 |
| 포션 과다 사용 | 폭식 | 탐욕 |
| 동료 장비 벗겨서 주력에게 | 시기 | 색욕 |

**전투/진행**

| 행동 | 올라가는 죄종 | 내려가는 죄종 |
|------|-------------|-------------|
| 패배 후 즉시 재도전 | 분노 | 나태 |
| 패배 후 포기 | 나태 | 분노 |
| 쉬운 스테이지만 반복 | 나태 | 교만 |
| 최고 난이도 도전 | 교만 | 나태 |
| 충분한데 파밍 반복 | 탐욕 | 폭식 |

### 선택지 설계 원칙

1. **모든 선택지에 정답이 없다** — 어떤 선택이든 한 죄종이 올라가고 다른 죄종이 내려간다
2. **게임플레이 자체가 선택지** — 이벤트뿐 아니라 영웅 관리, 자원 관리, 파밍 습관도 반영
3. **같은 행동이라도 맥락이 다르면 다른 죄종** — "거절"이 교만일 때도, 나태일 때도 있음

## 6. 영웅 시스템

### 영웅 구조

각 영웅은 다음 요소로 구성:

| 요소 | 내용 | 결정 시점 |
|------|------|----------|

### 직업 5종

직업은 영웅의 고정 특성. 전직 없음.

| 직업 | 주스탯 | 역할 |

| **힐러(Healer)** | INT+VIT | 힐/버프 |

### 영웅 27체 + 바알

**바알** = HoMM3식 지휘관. 전투에 직접 참여하지 않고, 레벨 기반 버프 + 사기 보정 제공.

| 직업 | 영웅 (죄종) |
|------|------------|
| **전사** (5) | 사탄(분노), 벨제붑(폭식), 아바돈(분노), 둘라한(분노), 네피림(교만) |
| **기사** (5) | 벨페고르(나태), 몰록(분노), 아스타로트(나태), 파주주(나태), 다곤(탐욕) |
| **마법사** (9) | 메피스토펠레스(탐욕), 릴리스(색욕), 유키온나(나태), 세라핌(교만), 레비아탄(시기), 아스모데우스(색욕), 나르키소스(시기), 인큐버스(색욕), 사이렌(색욕) |

### 사기 스킬

사기가 임계치에 도달하면 추가 스킬이 해금된다. 각 영웅마다 2단계.

```
사기 60+ → 사기 스킬 1 해금 (영웅별 고유)
사기 80+ → 사기 스킬 2 해금 (영웅별 고유) + 연계 스킬 발동 가능
```

사기가 임계치 아래로 내려가면 스킬이 다시 잠긴다 (느리게 — 즉시 잠기지 않고 3전투 유지 후 잠김).

### 사기 상태별 전투 행동

| 사기 구간 | 전투 효과 | 레퍼런스 |
|----------|----------|---------|
| **충성** (80+) | 사기 스킬 2 + 연계 스킬 + 특수 대사 | DD2 긍정 관계 |
| **고양** (60+) | 사기 스킬 1 + 추가 행동 확률 10% | HoMM3 +사기 |
| **보통** (40+) | 기본 상태 | - |
| **불만** (20+) | 명령 불복 10% (턴 스킵) | HoMM3 -사기 |
| **절망** (0+) | 명령 불복 25% + 아군 공격 가능 | DD1 Affliction |

### 선술집 — 영웅 영입

선술집에 시간마다 영웅이 방문. 골드로 영입.

**좌석: 3석**

| 파라미터 | 값 |
|---------|-----|

| 같은 영웅 보유 제한 | 1체만 |

## 7. 전투 시스템

### 기본 구조

- **3인 파티 자동전투**: 영웅 3명 vs 적 다수
- **행동 게이지 기반**: 각 유닛의 speed에 비례하여 게이지 충전
- **게이지 100% → 행동**: 가장 빨리 찬 유닛이 먼저 행동
- **서버 시뮬레이션**: 서버에서 전투 결과를 계산, 클라이언트에서 재생
- **바알**: 전투 참여하지 않음 (지휘관 버프 + 사기 보정만)

### 행동 순서

```
모든 유닛 게이지 동시 충전 (speed 비례)
    ↓
게이지 100% 도달 → 행동 (기본공격 or 스킬)
    ↓
사기 상태 체크:
  - 충성/고양: 정상 행동 + 추가 행동/스킬 가능
  - 보통: 정상 행동
  - 불만: 10% 확률로 턴 스킵
  - 절망: 25% 확률로 턴 스킵 or 아군 공격
    ↓
적 전멸 → 다음 웨이브 or 클리어
아군 전멸 → 패배 → 마을 귀환
```

### 스킬 발동

- 각 영웅은 메인 스킬 1개 (고정)
- 사기 60+ → 사기 스킬 1 추가
- 사기 80+ → 사기 스킬 2 추가 + 연계 스킬
- 스킬 게이지: 행동 게이지와 별도 충전, 100% 도달 시 다음 행동에서 발동

### 연계 스킬 (사기 80+)

파티 내 영웅 2명 이상이 사기 80+ 이고 죄종 관계가 생성/강화일 때, 확률적으로 연계 스킬 발동.

```
예시: 사탄(분노, 사기 85) + 레비아탄(시기, 사기 82)
  → 분노+시기 = 강화 관계
  → 연계 스킬 "복수의 시선" 발동 가능
```

### 상태이상 (챕터 테마 연동)

| 상태이상 | 효과 | 지속 | 챕터 |
|---------|------|------|------|
| 화상 (burn) | 매 턴 최대HP 5% 데미지 | 3턴 | Ch1 분노 |
| 독 (poison) | 매 턴 최대HP 5% 데미지 | 3턴 | Ch2 시기 |
| 동결 (freeze) | 행동 불가 | 2턴 | Ch4 나태 |
| 매혹 (charm) | 같은 편 공격 | 2턴 | Ch6 색욕 |

### 전투 보상

| 요소 | 보상 |
|------|------|
| 일반 몬스터 | 골드 + 경험치 |
| 정예 몬스터 | 골드 + 경험치 + 장비 |
| 스테이지 보스 | 골드 + 경험치 + 희귀 장비 |
| 챕터 보스 | 전설 장비 + 다음 챕터 해금 |

### 사망 및 패배

- **파티 전멸 시**: 마을 귀환, 획득 아이템 유지
- **경험치 패널티**: 현재 레벨 경험치의 10% 차감 (레벨다운 없음)
- **전원 사기 -5** (패배 페널티)

## 8. 능력치 시스템

### 기본 능력치 5종

| 능력치 | 약칭 | 역할 |
|--------|------|------|
| **힘(Strength)** | STR | 물리 공격력 |
| **민첩(Dexterity)** | DEX | 공격속도 |
| **체력(Vitality)** | VIT | HP + 방어력 |
| **운(Luck)** | LCK | 치명타 확률 |
| **지능(Intelligence)** | INT | 마법 공격력 |

> 명중/회피 삭제 (자동전투에서 빗나감은 답답함만 유발. 100% 명중).
> 마나 없음 (스킬은 쿨다운으로만 제한).

### 스탯 공식

| 세부 스탯 | 공식 | 담당 |
|-----------|------|------|
| 물리 공격력 (ATK) | `(STR×2 + 무기dmg) × (1 + STR×0.005)` | STR |
| 마법 공격력 (MATK) | `(INT×2) × (1 + INT×0.005)` | INT |
| 최대 HP | `100 + VIT×10` | VIT |
| 방어력 (DEF) | `VIT×0.5 + 방어구DEF` | VIT |
| 행동 게이지 충전 | `기본속도(10) + DEX×0.3` | DEX |
| 치명타 확률 | `LCK×0.5%` (최대 80%) | LCK |
| 치명타 데미지 | `×1.5` (고정) | - |
| 방어 감소율 | `DEF / (DEF + 100)` | VIT |

### 데미지 공식

```
최종 데미지 = max(1, ATK × 스킬배율 - 적DEF) × 치명타배율(발동 시)
```

### 영웅 성장

- 영웅 베이스 스탯은 hero_base.csv에 고정
- 레벨업 시 스탯 자동 증가 (직업별 성장 곡선)
- 스탯 직접 투자 불가
- 최대 레벨: 50

## 9. 장비 시스템

### 장비 슬롯 — 3슬롯

각 영웅은 3개 장비 슬롯을 가진다.

| 슬롯 | 종류 | 베이스 스탯 |

| 장신구 | 반지/목걸이/부적 | 유틸 (속도/치명타/저항 등) |

### 장비 등급

| 등급 | 색상 | 접사 | 획득처 |
|------|------|------|--------|
| **일반** | 흰색 | 없음 | 필드 드롭 |
| **매직** | 파란색 | 접두 1개 (죄종) | 필드 드롭 |
| **레어** | 노란색 | 접두 + 접미 (죄종) | 보스 드롭 |
| **유니크** | 금색 | 고정 접사 | 챕터 보스 전용 |

### 죄종 접사

## 10. 챕터 및 스테이지 구조

### 7챕터 구조

| 챕터 | 죄악 | 배경 | 챕터 보스 | 성경 모티프 |
|------|------|------|----------|-----------|
| 1 | 분노 | 불타는 전장 | **사탄** | 카인과 아벨 |
| 2 | 시기 | 뒤틀린 숲 | **레비아탄** | 요셉과 형제들 |
| 3 | 탐욕 | 황금의 사막 | **맘몬** | 유다의 배신 |
| 4 | 나태 | 망각의 동토 | **벨페고르** | 요나의 도주 |
| 5 | 폭식 | 심연의 동굴 | **바알제붑** | 에서의 장자권 |
| 6 | 색욕 | 타락한 궁전 | **아스모데우스** | 삼손과 들릴라 |
| 7 | 교만 | 신의 폐허 | **루시퍼** | 바벨탑 + 루시퍼의 추락 |

### 스테이지 구조

- 각 챕터: 3스테이지 + 보스 스테이지
- 각 스테이지: [일반×3 + 정예×1] × 3웨이브 + 스테이지 보스
- 보스 스테이지: 2웨이브 + 스테이지 보스 + 챕터 보스

### 스테이지 진행

```
마을 → 스테이지 선택 → 입장
    ↓
웨이브 사이: 원정 이벤트 (랜덤, 1~2회)
    ↓
웨이브 1~3 + 보스 → 클리어 → 마을 귀환
```

### 스토리 전달

- **첫 클리어**: 스토리 모드 (이벤트 선택지 + 보스 대사 + 컷씬)
- **반복 플레이**: 던전 모드 (원정 이벤트만 등장, 서사 요소 생략)
